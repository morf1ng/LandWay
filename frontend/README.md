# LandWay — frontend хакатона

## Запуск

```bash
npm install
npm run dev -- -p 3001
```

По умолчанию frontend запрашивает `http://127.0.0.1:8000/api`. Для другого адреса укажите `NEXT_PUBLIC_API_URL` в `.env.local`.

## Карта и инфраструктура

Карта использует Leaflet, координаты узлов из `GET /api/map` и слой OpenStreetMap. Метки положения груза между узлами **расчётные**, не GPS. Проценты загрузки портов в текущей базе бэкенда — **демонстрационные**. Оперативной загрузки ж/д участков сейчас нет. Блок инфраструктуры показывает только порты и участки выбранного маршрута и явно указывает отсутствие оперативного источника.

Frontend готов к предложенному, пока **не согласованному** контракту `GET /api/infrastructure/status`. После реализации бэкендом поставьте `NEXT_PUBLIC_INFRASTRUCTURE_STATUS_ENABLED=true` в `.env.local`:

```json
{
  "ports": [
    {
      "name": "Махачкала",
      "workload": 72,
      "sourceKind": "live",
      "sourceName": "Название подтверждённого поставщика",
      "observedAt": "2026-11-12T10:30:00+03:00"
    }
  ],
  "rail": [
    {
      "from": "Саратов",
      "to": "Астрахань",
      "workload": 81,
      "delayMinutes": 95,
      "sourceName": "Название подтверждённого поставщика",
      "observedAt": "2026-11-12T10:28:00+03:00"
    }
  ]
}
```

Поля `sourceName` и `observedAt` обязательны для оперативных значений. Необходимо уточнить у поставщика, что означает `workload` (занятость причалов, очередь судов, загрузка станции или участка), интервал обновления и условия доступа. При недоступности API интерфейс остаётся на карте и помечает показатели как демо или «Нет данных».

## Риск и уведомления

Текущий `GET /api/analytics` возвращает результат демонстрационной эвристики бэкенда, а не обученной ИИ-модели. После подключения источника бэкенд должен сохранять снимок данных с временем и источником, пересчитывать риск по конкретному маршруту, сравнивать прогноз с предыдущим и создавать уведомление только при новом событии или существенном изменении риска. Уведомление должно содержать груз, причину, ожидаемое влияние на ETA, рекомендуемое действие, время расчёта и ссылку на карточку. Текстовое объяснение ИИ может использовать уже рассчитанные факторы, но не подменяет расчёт или источник данных.
